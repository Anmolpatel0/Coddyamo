# CODDYAMO – Developer Brand and Portfolio Website

**CODDYAMO – BUILD. CODE. CREATE.** is a technology brand and developer portfolio website founded by Anmol Patel. The platform showcases web development projects, programming skills, internship experience, GitHub repositories, and developer resources.

## Project Overview

CODDYAMO is a responsive, front-end website developed to establish a professional online presence and provide visitors with access to software projects and development resources.

The website introduces the founder, presents technical skills and internship experience, highlights featured projects, and connects visitors to GitHub and social media profiles.

## Live Website

- **GitHub Repository:** https://github.com/Anmolpatel0/Coddyamo
- **GitHub Profile:** https://github.com/Anmolpatel0

## Key Features

- **Developer Portfolio:** Founder profile, academic background, technical skills, and professional experience.
- **Project Showcase:** Featured web development and Python projects with live demo and source code links.
- **Internship Experience:** Web Development and Python internship information.
- **GitHub Integration:** JavaScript implementation using the GitHub REST API to retrieve public repository information.
- **Repository Search and Filtering:** Search repositories and filter them by programming language.
- **Repository Sorting:** Sort repositories by name, stars, or last updated date.
- **Responsive User Interface:** Layout designed for desktop and mobile devices.
- **Theme Switching:** Dark and light theme functionality.
- **Project Downloads:** Links to project source code ZIP archives and setup instructions.
- **Contact and Social Links:** GitHub, LinkedIn, Instagram, email, and Telegram community section.

## Installation and Local Setup

This project is a front-end website and does not require a backend server for its basic local setup.

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Git (optional)

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/Anmolpatel0/Coddyamo.git
   ```

2. Open the project folder:

   ```bash
   cd Coddyamo
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html` in a browser or use the VS Code Live Server extension.
